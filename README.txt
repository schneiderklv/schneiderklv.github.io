LIDIYA SCHNEIDER – PORTFOLIO V1

Was ist enthalten?
- index.html = die Webseite
- style.css = Design
- script.js = Klick-Funktionen
- assets/pdf = später kommen hier CV und kurze Projekt-PDFs hinein

So testest du die Seite:
1. Entpacke den ZIP-Ordner.
2. Öffne index.html mit Doppelklick.
3. Die Seite öffnet sich im Browser.
4. Teste:
   - "Projekt öffnen"
   - Kompetenz-Buttons
   - LinkedIn
   - E-Mail

Was ist jetzt enthalten?
- Lebenslauf als PDF im Hero- und Kontaktbereich
- Fünf PDF-Kurzauszüge der Hauptprojekte

Was noch möglich ist?
2. Optional: letzte Textkorrekturen
3. Danach Upload zu GitHub Pages
